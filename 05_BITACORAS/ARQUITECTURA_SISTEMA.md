# Arquitectura de Neural Finance

## Componentes principales

- API publica de MEXC.
- Backend Python y FastAPI.
- Modelos predictivos LSTM.
- Agente de inteligencia artificial con Ollama.
- Base de datos SQLite.
- Frontend React y TypeScript.
- Simulador de operaciones ficticias.
- Centro de notificaciones academicas.

## Flujo de informacion

1. Consulta de datos publicos de mercado.
2. Procesamiento de informacion en el backend.
3. Evaluacion experimental mediante modelos LSTM.
4. Visualizacion de resultados en el frontend.
5. Simulacion academica de operaciones.
6. Calculo de patrimonio y PnL.

## Centro de notificaciones

Modulo independiente de eventos de demostracion.

Permite almacenar eventos localmente y preparar
borradores de correo mediante mailto.

No recibe automaticamente decisiones predictivas.

## Alcance del sistema

Proyecto academico de inteligencia artificial,
analisis financiero y simulacion.

No ejecuta operaciones financieras reales.
